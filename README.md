# som3aware — portfolio

TUI-style portfolio. React 19 + Tailwind CSS v4 on Vite, served as static files from Cloudflare Pages.

## Develop

```bash
bun install
bun run dev      # http://localhost:3000
bun run typecheck && bun run lint && bun run test && bun run build
```

`?plain` shows the same content as one readable page.

## Deploy

```bash
bun run deploy
```

`bun run build` first runs `tools/seo.tsx` (also `bun run seo`), which writes `robots.txt`, `sitemap.xml`, `llms.txt` and `llms-full.txt` into `public/` from the site content; commit them. `VITE_SITE_URL` sets the origin they use (default `https://som3aware.pages.dev`). Then it builds to `dist/client`, the output dir in `wrangler.jsonc`.

## Where things are

| Concern                         | Location                                                                                                                                                                                                      |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| All content                     | `src/content/index.tsx`                                                                                                                                                                                       |
| Content building blocks         | `src/components/content.tsx`                                                                                                                                                                                  |
| Workspace (keys, panes, modals) | `src/components/Tui.tsx`                                                                                                                                                                                      |
| Plain page                      | `src/components/Plain.tsx`                                                                                                                                                                                    |
| Hash routes                     | `src/lib/route.ts` (tested in `route.test.ts`)                                                                                                                                                                |
| Tailwind tokens                 | `src/styles.css`                                                                                                                                                                                              |
| Themes                          | `src/styles/themes.css`, `src/lib/themes.ts`: generated by `tools/gen_themes.py tools/themes`; extra themes (Flexoki, Vesper, GitHub, Ayu, Vitesse) written by `tools/extra_themes.py` from official palettes |
| Fonts                           | list + first paint in the `index.html` boot script, `@font-face` in `src/styles/fonts.css`, files and sources in `public/fonts`                                                                               |
| Icons                           | `src/icons`: Simple Icons (npm `simple-icons`), plus five Devicon icons copied as path data                                                                                                                   |
| Changelog                       | `CHANGELOG.md`, shown as the changelog tab (`#/changelog`)                                                                                                                                                    |
| CV PDF, logos                   | `public/docs`, `public/icons`                                                                                                                                                                                 |
| Design plan                     | `plan.md`                                                                                                                                                                                                     |

The previous TanStack Start site is tagged `v2`.
