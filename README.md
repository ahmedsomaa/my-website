# som3aware — portfolio

TUI-style static site. Plain HTML, CSS and JS, no build step.

## Develop

```bash
python3 -m http.server 3000   # http://localhost:3000
```

## Deploy

Cloudflare Pages serves the repo root (`wrangler.jsonc`). Build command: none.

## Where things are

| Concern        | Location                                  |
| -------------- | ----------------------------------------- |
| Page + content | `index.html`                              |
| Behaviour      | `tui.js`                                  |
| Styles         | `tui.css`, `fonts.css`                    |
| Themes         | `themes.css`, `themes.js` (generated by `tools/gen_themes.py`) |
| CV PDF         | `docs/`                                   |
| Design plan    | `plan.md`                                 |

The previous TanStack Start site is tagged `v2`.
